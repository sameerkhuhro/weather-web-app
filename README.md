
# 🌦️ Weather Web App

A responsive and user-friendly weather web application that displays real-time weather information using a public weather API.

---

## 🌐 Live Demo

🔗 https://sameerkhuhro.github.io/weather-web-app/

---

## 🚀 Features

- 🌍 Search weather by city name  
- 🌡️ Real-time temperature, humidity, and weather conditions  
- 📱 Fully responsive design  
- 🎨 Clean and modern UI  
- ⚡ Fast and lightweight  

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **Weather API**
